# Repository instructions

## Markdown section numbering

For every Markdown document with sections, leave its document title unnumbered and add a linked `Index` near the beginning listing every section. Number section headings by depth in the repeating sequence number, letter, number, letter: top-level sections use `1.`, nested sections use `a.`, then `1.a.1`, then `1.a.1.a`, continuing the pattern for deeper headings. Keep index labels and links synchronized with the headings. Preserve the exact section heading text consumed by the existing documentation checks in `NOW.md` and `CHANGELOG.md`; list their numbered section labels in the index.
